# القيصر | مركز الشرح والحلول الذكي

مشروع Next.js + React + Supabase، بواجهة عربية RTL وثيم أسود/ذهبي.

## التشغيل على Windows
1. ثبّت Node.js (يفضل إصدار LTS حديث).
2. فك ضغط المشروع وافتح المجلد في VS Code.
3. افتح Terminal داخل المجلد ونفّذ:

```bash
npm install
```

4. انسخ `.env.local.example` وسمّ النسخة `.env.local`، ثم ضع بيانات مشروع Supabase.
5. افتح Supabase ثم SQL Editor وشغّل `supabase/schema.sql`.
6. أنشئ حسابات الطلاب في Supabase Auth بالبريد الاصطناعي التالي لكل كود:

`lowercase(STUDENT_CODE)@students.example.com`

مثال: الكود `MM-2027-001` يصبح البريد `mm-2027-001@students.example.com`، وكلمة المرور هي كلمة المرور المخصصة للطالب. بعد إنشاء حساب Auth، أضف صف profile بنفس UUID في `profiles`، وصف الكود في `student_codes`. لا تضع service_role key في المتصفح.

7. شغّل:

```bash
npm run dev
```

ثم افتح http://localhost:3000

## إعداد ملف البيئة
- `NEXT_PUBLIC_SUPABASE_URL`: رابط مشروع Supabase.
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`: مفتاح anon/publishable.

## ما هو جاهز في النسخة الحالية؟
- شاشة دخول بالكود وكلمة المرور عبر Supabase Auth.
- اختيار المرحلة لأول مرة وحفظها في `profiles.education_system` (القيمتان المخزنتان: `الثانوية العامة` أو `البكالوريا`).
- توجيه الطالب حسب المرحلة المحفوظة.
- فهرس البكالوريا والثانوية بالدروس التي أرسلها صاحب المشروع.
- صفحات دروس بهيكل شرح وتدريب تفاعلي تجريبي.
- جداول مبدئية لتقدم الطالب ومحاولات التقييم.

## ما يحتاج استكمالاً قبل الإطلاق
- استيراد محتوى ملفات Word إلى محرر الدروس/قاعدة المحتوى.
- إدخال الأسئلة الفعلية ومفاتيح الإجابات والتفسيرات.
- استكمال لوحة الإدارة لإضافة وتعديل الدروس والاختبارات.
- ربط التقييمات بلوحة نتائج المعلم.
- إعداد آلية إنشاء حسابات الطلاب دفعة واحدة من لوحة آمنة.
- اختبار سياسات RLS مع حسابات تجريبية قبل نشر الموقع.

## ملاحظات أمنية
لا تستخدم مفتاح Supabase `service_role` داخل كود المتصفح أو `.env` الذي يتم رفعه إلى GitHub. لا تحفظ كلمات مرور الطلاب كنص عادي في أي جدول. المصادقة هنا تتم من خلال Supabase Auth. اختيار المرحلة محفوظ في قاعدة البيانات، وتقيّد سياسة التحديث تغييره بعد أول اختيار.
